# 多数据库能力矩阵

本项目支持通过 `AIGBOOKS_DATABASE_URL` 配置切换 PostgreSQL / SQLite / MySQL 三种数据库存储与全文检索。下表列出三方言在不同能力维度的差异与降级方案。

## 能力矩阵

| 能力 | PostgreSQL | SQLite | MySQL |
|------|-----------|--------|-------|
| **驱动** | `asyncpg` | `aiosqlite` | `asyncmy` |
| **默认 URL 示例** | `postgresql+asyncpg://user:pwd@host:5432/db` | `sqlite+aiosqlite:///./var/aigbooks.db` | `mysql+asyncmy://user:pwd@host:3306/db` |
| **IP 字段（INET）** | 字符串化 `String(45)`（兼容 IPv4/IPv6） | 字符串化 `String(45)` | 字符串化 `String(45)` |
| **UPSERT** | `INSERT ... ON CONFLICT (...) DO UPDATE` | `INSERT ... ON CONFLICT (...) DO UPDATE` | `INSERT ... ON DUPLICATE KEY UPDATE` |
| **大表自增主键** | `BIGSERIAL` | `INTEGER PRIMARY KEY`（rowid） | `BIGINT AUTO_INCREMENT` |
| **全文检索索引** | `tsvector` 列 + `GIN` 索引 + DB 触发器维护 | `FTS5` 虚拟表 `books_fts`/`reports_fts` + 同步触发器 | `FULLTEXT ... WITH PARSER ngram` |
| **中文分词（写入）** | PG `simple` 配置按字索引 + 应用层 jieba `search_text` 列兜底 | 应用层 jieba `cut_for_search` 切词 + 空格拼接写入 `search_text` 列，FTS5 索引该列 | MySQL `ngram` parser 字符 2-gram + 应用层 jieba `search_text` 列兜底 |
| **中文搜索召回** | 字符级召回（中文按字）+ jieba 切词增强 | 词级召回（jieba 切词后空格分隔，FTS5 unicode61 视为 token） | 字符 2-gram 召回 |
| **触发器维护 FTS** | DB 端 `plpgsql` 触发器 | SQLite 触发器同步主表 → FTS5 影子表 | MySQL FULLTEXT 直接作用于主表，无需触发器 |
| **`report_count` 计数触发器** | DB 端 plpgsql 触发器 | SQLite 触发器 | MySQL 触发器 |
| **`server_default` 时间字段** | `func.now()` | `CURRENT_TIMESTAMP`（SQLAlchemy 翻译） | `CURRENT_TIMESTAMP` |
| **方言分支** | `INTEGER PRIMARY KEY` 用 BigInteger | `INTEGER PRIMARY KEY`（自动 rowid） | `BIGINT AUTO_INCREMENT` |
| **`asyncmy`/`asyncpg` 兼容性** | N/A | N/A | N/A |

## 写入侧：search_text 自动填充

`Book.search_text` 和 `Report.search_text` 列在三方言下都存在，由 SQLAlchemy ORM event listener (`before_insert` / `before_update`) 自动填充：

```python
def _join_search_text(*parts):
    tokens = set()
    for p in parts:
        tokens.update(cut_for_search(p))
    return " ".join(sorted(tokens))
```

- **SQLite**：FTS5 影子表通过触发器读取 `search_text` 列索引。
- **PostgreSQL**：原 `tsv_meta` / `tsv_desc` 列由 DB 触发器从 `title/author/description` 维护，不依赖 `search_text`（保留以备将来扩展）。
- **MySQL**：FULLTEXT 直接索引 `title/author/description`，不依赖 `search_text`。

## SQLite 特殊配置

`app/database.py` 在 SQLite 方言下额外设置：

```sql
PRAGMA journal_mode = WAL
PRAGMA busy_timeout = 5000
PRAGMA synchronous = NORMAL
PRAGMA foreign_keys = ON
```

避免并发 `SQLITE_BUSY`、提升写入性能。

## Alembic 迁移

`backend/alembic/versions/001_init.py` 同文件按 `bind.dialect.name` 分支：

```python
if dialect == "postgresql":
    _upgrade_postgres()  # tsv_* 转 TSVECTOR + 触发器 + GIN
elif dialect == "sqlite":
    _upgrade_sqlite()    # FTS5 影子表 + 同步触发器
elif dialect == "mysql":
    _upgrade_mysql()     # FULLTEXT WITH PARSER ngram
```

SQLite 自动启用 `render_as_batch=True`（`alembic/env.py`），解决 SQLite 缺 `ALTER COLUMN` 的问题。

## 切换数据库步骤

1. 修改 `.env` 中 `AIGBOOKS_DATABASE_URL`
2. `uv sync --python 3.11`（首次安装新方言 driver）
3. `alembic upgrade head`（按方言建表）
4. `uvicorn app.main:app`

## 已弃用方案（参考）

- **SQLite FTS5 unicode61 直接索引原始文本**：CJK 字符不被索引，中文搜索空召回（2026-07-31 验证）
- **SQLite FTS5 trigram**：CJK 不支持（2026-07-31 验证）
- **SeekDB 嵌入式模式**：ONNX 模型加载失败 + 嵌入式中文分词不工作（2026-07-31 验证）
- **PG zhparser 扩展**：超出 MVP 范围，未启用
