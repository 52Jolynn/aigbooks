# 通用编号标识符实施计划（ISBN / ISSN / ISSN-L）

## 计划概述

- **目标**：将聚合根从"单一 ISBN 字段"重构为"通用 `(type, identifier)` 二元组"，一次实施支持 `isbn` / `issn`（及预留 `issn-l`），URL 改为 `/api/identifiers/{type}/{identifier}`，封面按 `type` 子目录存储，前端表单 / OCR 同步支持三套正则。
- **范围**：
  - ✅ DB 迁移（`books` → `identifiers`，FK 改名，新增 `type` 列）
  - ✅ 后端 ORM / Schema / Router / Service / RSS 全链路调整
  - ✅ 前端 API / Router / 视图 / OCR / i18n 调整
  - ✅ 后端测试 / e2e 同步更新
  - ❌ 不做：旧 `/api/books/{isbn}` 路由兼容（用户已确认放弃兼容）
  - ❌ 不做：ISSN-L 业务识别（类型枚举预留，前端表单不暴露）
- **预期成果**：
  - 单一类型 Schema（`IdentifierType` Enum）覆盖图书与期刊聚合根
  - `POST /api/reports` 表单接受 `type` + `identifier`，UPSERT 联合唯一
  - `GET /api/identifiers/{type}/{identifier}` 详情按 type 区分
  - 前端 OCR 同时识别 ISBN-10/13 与 ISSN-8
- **预计工时**：3 工作日（1 后端 + 1 前端 + 0.5 测试 + 0.5 e2e 烟测 + 回滚演练）

## 需求背景

- **原始需求**：让 AIGBooks 支持举报期刊/连续出版物（ISSN），而不是仅限图书（ISBN）。
- **澄清记录**：

| 决策点 | 选择 | 理由 |
|---|---|---|
| 存储模型 | `(type, identifier)` 通用二元组 | 扁平、易扩展未来 DOI / arXiv ID |
| `type` 取值 | `isbn` / `issn` / `issn-l`（字符串） | 语义自描述；预留 ISSN-L |
| URL 形态 | `/api/identifiers/{type}/{identifier}` | RESTful、扩展性强 |
| 表名 | `books` rename 为 `identifiers` | 语义最准确 |
| FK 字段 | `reports.book_id` rename 为 `reports.identifier_id` | 与聚合根同步 |
| 封面路径 | `covers/{type}/{identifier}{ext}` 子目录 | 防 ISBN/ISSN 编号意外碰撞 |
| 旧路由兼容 | **不保留** | 用户已确认放弃 |
| 实施节奏 | **一次性全量** | 用户已确认 |
| ISSN-L | 预留 enum，前端不暴露 | 用户已确认 |

- **业务价值**：扩展举报覆盖范围到期刊、丛书、年鉴等连续出版物；架构上为未来 DOI/arXiv ID 等学术标识符预留扩展位。
- **成功标准**：
  - `POST /api/reports` 同时接受 `type=isbn` 与 `type=issn`，UPSERT 联合唯一不冲突
  - `GET /api/identifiers/isbn/9787000000001` 返回图书详情
  - `GET /api/identifiers/issn/1003-7055` 返回期刊详情（手动插入数据后）
  - `e2e/test_api.py` 涵盖 ISBN 与 ISSN 两条端到端路径，全绿
  - `npm run lint && npm run typecheck` 全绿
  - `ruff check backend/` 全绿

## 设计原则遵循

基于项目既有代码风格：

1. **方言无关**：DB 迁移与 ORM 类型沿用 `app/db/constants.py` 模式，type 列用 `String(16)`（与 `IpAddress` 类型类似思路）
2. **Schema 单一职责**：`app/schemas.py` 注释明确"业务规则放在 router 层"，校验正则继续在 router 层实现
3. **路由命名**：FastAPI 风格，路径参数小写，复数资源 → `/api/identifiers/{type}/{identifier}`
4. **枚举字面量**：用 `class IdentifierType(str, Enum)` 而非 `Literal`，便于 Pydantic / SQLAlchemy 复用
5. **前端类型同步**：`api/identifiers.ts` 与后端 Schema 字段一一对应，命名 1:1
6. **存储路径防御性**：封面按 `type` 分目录避免不同类型标识符碰撞

#### 迁移 SQL 草案（方言无关 + 方言分支）

```python
# 002_rename_books_to_identifiers.py
def upgrade() -> None:
    bind = op.get_bind()
    dialect = bind.dialect.name

    # 1. 新表（数据迁移中间态）
    op.create_table(
        "identifiers_new",
        sa.Column("id", sa.BigInteger().with_variant(sa.Integer, DIALECT_SQLITE), primary_key=True),
        sa.Column("type", sa.String(16), nullable=False, server_default="isbn"),
        sa.Column("identifier", sa.Text(), nullable=False),
        sa.Column("title", sa.Text(), nullable=False),
        sa.Column("author", sa.Text(), nullable=False),
        sa.Column("cover_path", sa.Text(), nullable=True),
        sa.Column("report_count", sa.Integer(), nullable=False, server_default="0"),
        sa.Column("tsv_meta", sa.Text(), nullable=True),
        sa.Column("search_text", sa.Text(), nullable=False, server_default=""),
        sa.Column("created_at", sa.DateTime(), nullable=False, server_default=sa.func.now()),
        sa.Column("updated_at", sa.DateTime(), nullable=False, server_default=sa.func.now()),
        sa.UniqueConstraint("type", "identifier", name="uq_identifiers_type_identifier"),
    )

    # 2. 数据回填（默认 type='isbn'）
    bind.execute(sa.text(
        "INSERT INTO identifiers_new (id, type, identifier, title, author, "
        "cover_path, report_count, tsv_meta, search_text, created_at, updated_at) "
        "SELECT id, 'isbn', isbn, title, author, cover_path, report_count, "
        "tsv_meta, search_text, created_at, updated_at FROM books"
    ))

    # 3. 处理 reports.book_id → identifier_id
    op.drop_table("reports")  # 简化：先 drop reports（FK 依赖）
    # 或更稳：ALTER TABLE reports RENAME COLUMN book_id TO identifier_id（方言分支）
    # 选择：分方言处理
    if dialect == DIALECT_POSTGRESQL:
        op.execute("ALTER TABLE reports RENAME COLUMN book_id TO identifier_id")
    elif dialect == DIALECT_SQLITE:
        # SQLite 12 步重建法（详见迁移文件）
        ...
    elif dialect == DIALECT_MYSQL:
        op.execute("ALTER TABLE reports CHANGE book_id identifier_id BIGINT NOT NULL")

    # 4. drop 旧 books
    op.drop_table("books")

    # 5. rename 新表
    op.rename_table("identifiers_new", "identifiers")

    # 6. 重建唯一索引 + 触发器/FTS（与 001 对齐）
    op.create_index("ix_identifiers_type_identifier", "identifiers", ["type", "identifier"], unique=True)
    # 方言分支：FTS5 影子表 / GIN / FULLTEXT 重建（参考 001_init.py 的方言分支）
    ...
```

> **关键决策**：FTS5 影子表（SQLite）与 tsvector 触发器（PG）需要重建，因为表名变化。新迁移需包含完整的方言分支，**不能**只 drop 后简单 recreate。

#### 核心设计要点

- **迁移采用"新建表 → 数据回填 → drop 旧表 → rename 新表"**，避免 SQLite ALTER TABLE RENAME COLUMN 的版本兼容陷阱（虽然 Python 3.12+ SQLite ≥ 3.25 支持，但 alembic 环境版本不可控）
- **`server_default="isbn"`**：旧数据回填时显式指定 `type='isbn'`，新增数据由应用层保证不空
- **触发器 / FTS5 重建**：参考 `001_init.py` 的方言分支，新增 `identifiers_fts`（SQLite）、`tsv_meta` 触发器（PG）

```python
# routers/identifiers.py
from app.db.constants import IdentifierType

_TYPE_TO_REGEX = {
    IdentifierType.ISBN: re.compile(r"^(?:\d{9}[\dX]|\d{13})$"),  # ISBN-10 + ISBN-13
    IdentifierType.ISSN: re.compile(r"^\d{4}-?\d{3}[\dX]$"),
    IdentifierType.ISSN_L: re.compile(r"^\d{4}-?\d{3}[\dX]$"),  # 与 ISSN 同形态
}

async def _validate_identifier(type_: str, identifier: str) -> None:
    if type_ not in IdentifierType:
        raise HTTPException(422, detail={"code": 422, "msg": f"不支持的 type: {type_}"})
    # 去连字符后再校验（兼容 OCR 输入）
    normalized = identifier.replace("-", "").replace(" ", "")
    if not _TYPE_TO_REGEX[type_].match(normalized):
        raise HTTPException(422, detail={"code": 422, "msg": f"{type_} 格式不正确: {identifier}"})
```

#### OCR 识别逻辑（关键）

```typescript
// frontend/src/ocr/index.ts
const ISBN_REGEX = /\b(?:97[89])?[-\s]?\d{1,5}[-\s]?\d{1,7}[-\s]?\d{1,7}[-\s]?[\dX]\b/;
const ISSN_REGEX = /\b\d{4}[-\s]?\d{3}[\dX]\b/;

export function recognizeText(raw: string): OCRResult {
  const isbnMatch = raw.match(ISBN_REGEX);
  const issnMatch = raw.match(ISSN_REGEX);

  // 优先级：ISBN-13 > ISBN-10 > ISSN
  // ISBN 与 ISSN 都匹配时（如 ISBN-10 长度 10，ISSN 长度 8，无碰撞），都返回
  return {
    isbn: isbnMatch?.[0]?.replace(/[-\s]/g, ''),
    issn: issnMatch?.[0]?.replace(/[-\s]/g, ''),
    identifierType: isbnMatch ? 'isbn' : issnMatch ? 'issn' : undefined,
    title: ...,
    author: ...,
    raw,
  };
}
```
