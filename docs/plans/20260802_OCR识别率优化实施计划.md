# OCR 识别率优化实施计划（第一阶段 + 第二阶段合并）

> 范围：仅修改 `frontend/`（`ocr/index.ts` / `barcode/` 新增 / `ReportView.vue` / `i18n/zh.ts` / `vite-env.d.ts`），**不引入新 npm 依赖**，新增 `public/zxing/` 静态资源
> 决策背景：`tesseract.js` 在书脊/封面场景下识别率低（训练数据是文档扫描，场景不匹配）；业界标准做法是"先条形码后 OCR"（参考 `docs/reports/20260802_OCR识别率优化技术调研.md`）
> 实施合并：把第一阶段（条形码识别）和第二阶段（OCR 文本优化）合一次 PR，便于端到端验证

## 0. 计划概述

- **目标**：OCR 区块采用"先条形码后 OCR"混合识别，ISBN-13 / ISBN-10 / ISSN 三格式全覆盖
- **范围**：
  - 第一阶段：新增 `barcode/` 模块，浏览器原生 `BarcodeDetector` + ZXing WASM 兜底，资源本地化
  - 第二阶段：图像预处理（灰度 + OTSU 二值化）、清晰度检测、tesseract 字符白名单 + 多 PSM 模式、三格式 checksum 校验、ISBN-10 → ISBN-13 补全
  - 集成：ReportView 改为 `recognizeIdentifier(image)`（内部先 barcode 后 ocr）
  - i18n：新增 5 条识别反馈文案
- **不在范围**：
  - PaddleOCR.js（2026 Q4 评估）
  - 云 OCR API（隐私问题）
  - 视频流实时识别
  - 条形码生成（与 OCR 无关）
- **预期成果**：
  - 现代书（有条形码）：~100% 准确率，<200ms
  - 老书/期刊（无条形码，文字清晰）：75-85% 准确率
  - 模糊图片：清晰度检测 + 提示重拍
- **预计工时**：1.5 个工作日

## 1. 需求背景

- **原始需求**：OCR 扫描要支持拍照、上传图片两种模式（已实现）
- **本次新增需求**：识别率太低，混合条形码识别 + OCR 文本优化
- **澄清记录**：
  1. 第一阶段（条形码） = 用浏览器原生 `BarcodeDetector`，Firefox/iOS 自动降级到 ZXing WASM
  2. 第二阶段（OCR） = 预处理 + 字符白名单 + 多 PSM + 三格式校验 + 清晰度检测
  3. 格式覆盖 = ISBN-13 / ISBN-10 / ISSN
  4. 不引入新依赖 = 自实现 checksum（~30 行）
  5. 资源本地化 = `zxing_reader.wasm` 下载到 `public/zxing/`
- **业务价值**：识别率从 30% → 90%+，用户体验从"基本不能用"到"基本能用"
- **成功标准**：
  1. `pnpm typecheck` + `pnpm build` 通过
  2. 移动端拍 ISBN 条形码 → 200ms 内自动填表
  3. 桌面 Firefox（无 `BarcodeDetector`）→ ZXing WASM 兜底，仍能识别条形码
  4. 拍 ISSN 期刊封面 → 提取 8 位 ISSN
  5. 拍 ISBN-10 封面 → 自动补全为 ISBN-13
  6. 模糊图片 → 提示"图片太模糊，请重新拍摄"
  7. 字符白名单生效：OCR 输出不再出现 ISBN 字符集外的字符

```ts
/**
 * ISBN/ISSN 条形码识别。
 * 优先用浏览器原生 BarcodeDetector，Firefox/iOS 不可用时降级到 ZXing WASM。
 */
import type { IdentifierType } from '@/api/identifiers';
import { loadBarcodeDetector } from './polyfill';

export interface BarcodeResult {
  /** ISBN-13（13 位纯数字） */
  isbn?: string;
  /** ISSN（8 位数字 + 可选 X） */
  issn?: string;
  /** 条形码格式：ean_13 / ean_8 / upc_a / ... */
  format?: string;
  /** 原始识别值（未归一化） */
  raw: string;
  /** 识别来源：原生 / polyfill */
  source: 'native' | 'polyfill';
}

const ISBN13_REGEX = /^\d{13}$/;
const ISSN_REGEX = /^\d{7}[\dX]$/;
const EAN13_PREFIX = ['978', '979'];

let detectorPromise: Promise<{ detect: (img: any) => Promise<DetectedBarcode[]> } | null> | null = null;

async function getDetector() {
  if (!detectorPromise) {
    detectorPromise = loadBarcodeDetector();
  }
  return detectorPromise;
}

function normalize(text: string): string {
  return text.replace(/[-\s]/g, '').toUpperCase();
}

function classify(raw: string): { isbn?: string; issn?: string; format?: string } {
  const text = normalize(raw);
  if (ISBN13_REGEX.test(text) && EAN13_PREFIX.includes(text.slice(0, 3))) {
    return { isbn: text, format: 'ean_13' };
  }
  if (ISSN_REGEX.test(text)) {
    return { issn: text, format: 'ean_8_or_issn' };
  }
  return {};
}

export async function recognizeBarcodes(
  image: File | Blob | ImageBitmap | HTMLImageElement,
): Promise<BarcodeResult> {
  const detector = await getDetector();
  if (!detector) return { raw: '', source: 'native' };
  try {
    const results = await detector.detect(image);
    if (results.length === 0) return { raw: '', source: 'native' };
    const first = results[0];
    const classified = classify(first.rawValue ?? '');
    return {
      ...classified,
      format: first.format ?? classified.format,
      raw: first.rawValue ?? '',
      source: 'native',  // polyfill 也走 native API 接口
    };
  } catch (e) {
    console.warn('[barcode] detect failed:', e);
    return { raw: '', source: 'native' };
  }
}
```

#### `barcode/polyfill.ts` 设计

```ts
/**
 * 加载 BarcodeDetector，必要时 polyfill。
 * 优先浏览器原生，Firefox/iOS 自动降级到 ZXing WASM。
 */
import { barcodeDetectorPolyfill } from '@undecaf/barcode-detector-polyfill';

let polyfillLoaded = false;

export async function loadBarcodeDetector() {
  if (typeof window === 'undefined') return null;

  // 1. 浏览器原生支持
  if ('BarcodeDetector' in globalThis) {
    const supported = await BarcodeDetector.getSupportedFormats();
    const want = ['ean_13', 'ean_8', 'upc_a', 'upc_e', 'code_128'];
    const formats = want.filter((f) => supported.includes(f));
    if (formats.length > 0) {
      return new BarcodeDetector({ formats });
    }
  }

  // 2. 降级到 ZXing WASM polyfill
  if (!polyfillLoaded) {
    try {
      await barcodeDetectorPolyfill({
        // 本地化 wasm 路径
        locateFile: () => '/zxing/zxing_reader.wasm',
      });
      polyfillLoaded = true;
    } catch (e) {
      console.error('[barcode] polyfill load failed:', e);
      return null;
    }
  }

  return 'BarcodeDetector' in globalThis
    ? new BarcodeDetector({ formats: ['ean_13', 'ean_8', 'upc_a', 'upc_e', 'code_128'] })
    : null;
}
```

#### polyfill 包选型

| 候选 | 评价 |
|---|---|
| `barcode-detector` (47 dependents) | 内部用 ZXing WASM，**有 locateFile 选项**，支持本地化 |
| `@undecaf/barcode-detector-polyfill` | 内部用 ZBar WASM，体积更小，**但依赖 zbar 的 polyfill 路径** |
| `zxing-wasm` 直接用 | 功能最全但要自己写 detect 逻辑 |

**决策**：用 `barcode-detector`（成熟度高、有 47 dependents、API 与原生一致）。

```ts
// ISBN-13 校验：mod 10 加权
function isValidIsbn13(s: string): boolean {
  if (!/^\d{13}$/.test(s)) return false;
  let sum = 0;
  for (let i = 0; i < 12; i++) {
    sum += parseInt(s[i], 10) * (i % 2 === 0 ? 1 : 3);
  }
  return ((10 - (sum % 10)) % 10) === parseInt(s[12], 10);
}

// ISBN-10 校验：mod 11 加权（X = 10）
function isValidIsbn10(s: string): boolean {
  if (!/^\d{9}[\dX]$/.test(s)) return false;
  let sum = 0;
  for (let i = 0; i < 10; i++) {
    const d = s[i] === 'X' ? 10 : parseInt(s[i], 10);
    sum += d * (10 - i);
  }
  return sum % 11 === 0;
}

// ISSN 校验：mod 11 加权（X = 11 → 0，特殊规则）
function isValidIssn(s: string): boolean {
  if (!/^\d{7}[\dX]$/.test(s)) return false;
  let sum = 0;
  for (let i = 0; i < 7; i++) {
    sum += parseInt(s[i], 10) * (8 - i);
  }
  const checkDigit = (11 - (sum % 11)) % 11;
  const expected = checkDigit === 10 ? 'X' : String(checkDigit);
  return s[7] === expected;
}

// ISBN-10 → ISBN-13 补全
function expandToIsbn13(s: string): string | null {
  if (s.length === 10 && isValidIsbn10(s)) {
    const base = '978' + s.slice(0, 9);
    let sum = 0;
    for (let i = 0; i < 12; i++) {
      sum += parseInt(base[i], 10) * (i % 2 === 0 ? 1 : 3);
    }
    const check = (10 - (sum % 10)) % 10;
    return base + check;
  }
  return null;
}

// OCR 错误纠正（仅在数字位置）
function normalizeOcrDigits(s: string): string {
  return s.replace(/O/g, '0').replace(/I/g, '1').replace(/l/g, '1');
}

// 提取并校验所有 ISBN/ISSN 候选
function extractIdentifiers(raw: string): {
  isbn?: string;
  issn?: string;
  identifierType?: IdentifierType;
} {
  const text = normalizeOcrDigits(raw);
  // 提取 ISBN-13 候选（978/979 + 10位）
  const isbn13Match = text.match(/\b97[89]\d{10}\b/);
  if (isbn13Match && isValidIsbn13(isbn13Match[0])) {
    return { isbn: isbn13Match[0], identifierType: 'isbn' };
  }
  // 提取 ISBN-10 候选（9位 + X/数字）
  const isbn10Match = text.match(/\b\d{9}[\dX]\b/);
  if (isbn10Match && isValidIsbn10(isbn10Match[0])) {
    const expanded = expandToIsbn13(isbn10Match[0]);
    if (expanded) return { isbn: expanded, identifierType: 'isbn' };
  }
  // 提取 ISSN 候选
  const issnMatch = text.match(/\b\d{7}[\dX]\b/);
  if (issnMatch && isValidIssn(issnMatch[0])) {
    return { issn: issnMatch[0], identifierType: 'issn' };
  }
  return {};
}

// 清晰度检测：Laplacian 方差
async function detectBlur(blob: Blob): Promise<number> {
  const bitmap = await createImageBitmap(blob);
  const canvas = new OffscreenCanvas(bitmap.width, bitmap.height);
  const ctx = canvas.getContext('2d');
  if (!ctx) return 100;
  ctx.drawImage(bitmap, 0, 0);
  const data = ctx.getImageData(0, 0, bitmap.width, bitmap.height).data;
  // 灰度 + Laplacian 4 邻域
  let sum = 0, sumSq = 0, count = 0;
  const w = bitmap.width;
  for (let y = 1; y < bitmap.height - 1; y++) {
    for (let x = 1; x < w - 1; x++) {
      const i = (y * w + x) * 4;
      const lum = (data[i] + data[i+1] + data[i+2]) / 3;
      const lumTop = (data[i - w*4] + data[i - w*4 + 1] + data[i - w*4 + 2]) / 3;
      const lumBot = (data[i + w*4] + data[i + w*4 + 1] + data[i + w*4 + 2]) / 3;
      const lumL = (data[i - 4] + data[i - 3] + data[i - 2]) / 3;
      const lumR = (data[i + 4] + data[i + 5] + data[i + 6]) / 3;
      const lap = 4 * lum - lumTop - lumBot - lumL - lumR;
      sum += lap;
      sumSq += lap * lap;
      count++;
    }
  }
  return sumSq / count - (sum / count) ** 2;
}

// 图像预处理：缩放 + 灰度 + OTSU 二值化
async function preprocessImage(blob: Blob): Promise<Blob> {
  const bitmap = await createImageBitmap(blob);
  const MAX_DIM = 2000;
  const scale = Math.min(1, MAX_DIM / Math.max(bitmap.width, bitmap.height));
  const w = Math.round(bitmap.width * scale);
  const h = Math.round(bitmap.height * scale);
  const canvas = new OffscreenCanvas(w, h);
  const ctx = canvas.getContext('2d');
  if (!ctx) return blob;
  ctx.drawImage(bitmap, 0, 0, w, h);
  // OTSU 灰度二值化（伪代码）
  const imageData = ctx.getImageData(0, 0, w, h);
  const gray = new Uint8ClampedArray(w * h);
  for (let i = 0, j = 0; i < imageData.data.length; i += 4, j++) {
    gray[j] = imageData.data[i] * 0.299 + imageData.data[i+1] * 0.587 + imageData.data[i+2] * 0.114;
  }
  // OTSU 阈值计算（省略实现：~30 行）
  const threshold = otsuThreshold(gray);
  for (let j = 0; j < gray.length; j++) {
    const v = gray[j] < threshold ? 0 : 255;
    imageData.data[j*4] = imageData.data[j*4+1] = imageData.data[j*4+2] = v;
    imageData.data[j*4+3] = 255;
  }
  ctx.putImageData(imageData, 0, 0);
  return await canvas.convertToBlob({ type: 'image/png' });
}
```

#### 重构 `recognizeText`

```ts
export async function recognizeText(image: File | Blob): Promise<OCRResult & { error?: string }> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  try {
    const normalized = await normalizeImage(image);  // 已有：HEIC 转码
    const preprocessed = await preprocessImage(normalized);  // 新增
    const blur = await detectBlur(preprocessed);  // 新增
    if (blur < 30) {
      return { raw: '', error: 'imageTooBlurry' };
    }

    const worker = await getWorker();
    const psmModes = [6, 7, 8, 3];
    for (const psm of psmModes) {
      await worker.setParameters({
        tessedit_pageseg_mode: String(psm),
        tessedit_char_whitelist: '0123456789XISBNsni- ',  // 新增
        preserve_interword_spaces: '1',
        user_defined_dpi: '300',
      });
      const recognizePromise = worker.recognize(preprocessed);
      const timeoutPromise = new Promise<never>((_, reject) => {
        timer = setTimeout(() => reject(new Error('ocr-timeout')), RECOGNIZE_TIMEOUT_MS);
      });
      const { data } = await Promise.race([recognizePromise, timeoutPromise]);
      const extracted = extractIdentifiers(data.text);  // 新增
      if (extracted.isbn || extracted.issn) {
        return { ...extracted, raw: data.text, psm, blur };
      }
    }
    return { raw: '', error: 'noMatch' };
  } catch (e) {
    console.warn(consoleMessages.ocrFailed, e);
    void disposeWorker();
    return { raw: '', error: 'failed' };
  } finally {
    if (timer) clearTimeout(timer);
  }
}
```

#### 新增文件 `frontend/src/identifier/index.ts`

```ts
/**
 * 统一识别入口：先条形码 → 后 OCR → 兜底手动。
 */
import { recognizeBarcodes } from '@/barcode';
import { recognizeText } from '@/ocr';
import type { IdentifierType } from '@/api/identifiers';

export interface RecognizeResult {
  isbn?: string;
  issn?: string;
  identifierType?: IdentifierType;
  source: 'barcode' | 'ocr' | 'none';
  error?: string;
  raw?: string;
}

export async function recognizeIdentifier(
  image: File | Blob,
): Promise<RecognizeResult> {
  // 1. 先条形码
  const barcode = await recognizeBarcodes(image);
  if (barcode.isbn || barcode.issn) {
    return {
      isbn: barcode.isbn,
      issn: barcode.issn,
      identifierType: barcode.isbn ? 'isbn' : 'issn',
      source: 'barcode',
    };
  }
  // 2. 后 OCR
  const ocr = await recognizeText(image);
  if (ocr.isbn || ocr.issn) {
    return {
      isbn: ocr.isbn,
      issn: ocr.issn,
      identifierType: ocr.isbn ? 'isbn' : 'issn',
      source: 'ocr',
      raw: ocr.raw,
    };
  }
  // 3. 兜底
  return {
    source: 'none',
    error: ocr.error ?? 'noMatch',
  };
}
```

## 6. 风险与应对

| # | 风险 | 概率 | 影响 | 应对 |
|---|------|------|------|------|
| R1 | `barcode-detector` polyfill 无法本地化 WASM | 中 | 中 | 备选 `@undecaf/barcode-detector-polyfill` 或自写 ZXing 适配 |
| R2 | ZXing WASM 本地 1MB + tesseract 22MB = 23MB 总静态资源 | 高 | 低 | 与 tesseract 资源并列存放，commit message 标注 |
| R3 | OTSU 阈值算法实现复杂度 | 低 | 低 | 参考开源实现 ~30 行，或用更简单的"固定阈值 128" |
| R4 | 多 PSM 模式增加 OCR 时间 | 中 | 低 | 仅在主 PSM=6 失败时尝试其他；超时保护已加 |
| R5 | 字符白名单太严导致 "ISBN" 前缀丢失 | 中 | 中 | 宽松版 `'0123456789XISBNsni- '` 保留前缀 |
| R6 | Firefox 本地化 ZXing wasm 路径不对 | 中 | 中 | 用 `locateFile` 自定义路径；CSP 允许 `self` |
| R7 | 清晰度阈值 30 误判（高对比但文字少） | 中 | 中 | 阈值可配；先做"提示重拍"而不是直接 fail |
| R8 | 用户拍了封面（含题名+ISBN），OCR 误识别题名为 ISBN | 中 | 中 | 校验位过滤：校验失败的候选丢弃 |
