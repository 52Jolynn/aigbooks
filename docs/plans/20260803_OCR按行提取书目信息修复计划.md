# OCR 按行提取书目信息修复计划

## 计划概述

- **目标**：修复版权页 OCR 字段错位，按行稳定提取题名、作者、ISBN 和摘要。
- **范围**：前端 OCR 文本解析、ISBN 展示格式、阶段回填与测试；不改 API、数据库和 OCR 引擎。
- **预期成果**：第一行填题名；著者/作者优先、国别姓名其次、译者兜底；ISBN/书号行提取并格式化 ISBN；其余行在摘要为空时填入摘要。
- **预计工时**：0.5 天。

## 需求背景

- OCR 原始文本保留换行，但现有 `extractCipInfo` 将全部空白折叠，随后斜杠正则跨字段吞并文本。
- **确认规则**：
  - 按换行符分割并清理空行。
  - 第一行作为题名。
  - `ISBN` 或 `书号` 行用于提取 ISBN；支持书号标签与数字跨行。
  - 作者匹配优先级：`著者/作者` 标签 → `[美]` 等国别姓名格式 → `译者`。
  - 已用于题名、作者、ISBN 的行不进入摘要；其余行组成摘要。
  - 摘要仅在当前为空时自动填充。
  - ISBN-13 表单展示为 `978-7-5086-7553-4`。

## 任务分解

### 任务 1：同步设计文档

- 明确 OCR 按行解析、作者优先级、摘要回填和 ISBN 展示格式。

### 任务 2：先补失败测试

- 使用用户提供的《心流》原始 OCR 文本复现题名/作者错位。
- 覆盖著者优先、国别姓名、译者兜底、书号跨行、ISBN 格式化。
- 覆盖摘要仅填充空字段，不覆盖已有摘要。

### 任务 3：实现按行字段解析

- 保留原始换行并清理每行空白。
- 第一非空行为题名。
- 标签驱动提取作者，避免出版发行等内容污染作者。
- 提取有效 ISBN/ISSN，并记录字段所占行。
- 返回剩余行组成的摘要。
- 保留必要的 CIP 兼容路径，但不再使用无边界的全文斜杠切分。

### 任务 4：实现即时回填与 ISBN 格式化

- OCR 阶段增加 `summary` 字段。
- 表单摘要为空时才应用 OCR 摘要。
- ISBN-13 按 `978-7-5086-7553-4` 分组显示；后端现有归一化校验保持兼容。

### 任务 5：清理与验证

- 清理被新解析器替代的贪婪正则与重复逻辑。
- 执行 `pnpm test`、`pnpm typecheck`、`pnpm build`。
- 更新计划状态为已完成。

## 验收用例

| 场景 | 预期 |
|---|---|
| 用户提供的《心流》文本 | 题名=`心流：最优体验心理学`；作者=`[美]米哈里·契克森米哈赖`；ISBN=`978-7-5086-7553-4` |
| 同时有著者和译者 | 取著者 |
| 无著者，有 `[美]姓名` | 取国别姓名 |
| 只有译者 | 取译者 |
| `书号：ISBN` 与数字分两行 | 正确组合并提取 ISBN |
| 摘要已有内容 | 不覆盖 |
| 摘要为空 | 填入未消费的其余行 |

## 风险与应对

| 风险 | 应对 |
|---|---|
| OCR 行顺序异常 | 仅对第一非空行采用题名规则，字段仍允许手工修正 |
| ISBN 分组不适用于所有出版社 | 当前按用户指定示例采用固定 `3-1-4-4-1` 展示分组，不影响归一化值 |
| 国别姓名误匹配 | 仅在无著者/作者标签时启用，并排除出版、印刷、版次等标签行 |
